# DERA 🌍

### Every Young Person Belongs Here

DERA is a youth-focused digital platform created to connect young people with opportunities, resources, career guidance, and educational support. The platform is designed to help young people make informed decisions about their education and future careers while providing access to useful opportunities in one place.

---

## 📌 About DERA

DERA brings together educational and career resources to help young people discover opportunities and take meaningful steps toward their future.

The platform focuses on making it easier for young people to:

* 🎓 Discover scholarship opportunities
* 📝 Access tertiary education forms and resources
* 🤖 Receive AI-powered career guidance
* 🧭 Discover suitable career paths
* 💡 Read inspirational stories and useful resources
* ❤️ Support youth-focused initiatives through donations
* 🚀 Explore opportunities for personal and professional development

---

## ✨ Features

### 🎓 Scholarship Hub

The Scholarship Hub allows users to discover scholarship opportunities and access information that can help them find financial support for their education.

### 📝 Forms Marketplace

DERA provides a marketplace where users can find and purchase available tertiary education forms and related resources.

### 🤖 AI Career Counsellor

The AI Career Counsellor provides users with an interactive way to ask questions about careers, education, skills, and professional development.

### 🧭 Career Discovery Quiz

The Career Discovery Quiz helps users explore career paths based on their interests, abilities, and educational level.

### 💳 Online Payments

DERA integrates online payment functionality to allow users to securely pay for available services and products.

### 💡 Inspirational Stories

Users can access inspirational stories and resources designed to encourage personal growth, ambition, and positive development.

### ❤️ Donations

DERA provides a way for individuals to support youth development initiatives through donations.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/vnngmalbini/DERA.git
```

### 2. Navigate to the Project

```bash
cd DERA
```

### 3. Backend Setup

Navigate to the backend directory:

```bash
cd Backend
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

### 4. Frontend Setup

Navigate to the frontend directory:

```bash
cd Frontend
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## 🔐 Environment Variables

DERA uses environment variables to protect sensitive information such as API keys, database credentials, and payment credentials.

Create a `.env` file and configure the required variables.

Example:

```env
SECRET_KEY=your_secret_key
DEBUG=True

DATABASE_URL=your_database_url

SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key

PAYSTACK_SECRET_KEY=your_paystack_secret_key

GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash
```

> ⚠️ **Important:** Never upload your actual `.env` file or secret API keys to GitHub.

## 🚀 Deployment

The DERA frontend can be deployed using **Vercel**, while the backend can be deployed using a suitable backend hosting platform.

Before deployment, ensure that:

* Environment variables are properly configured.
* The database is connected correctly.
* Frontend and backend API URLs are correctly configured.
* CORS settings are properly configured.
* Production builds work correctly.
* Secret credentials are not exposed.
